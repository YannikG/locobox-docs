# Anmelden

Locobox nutzt eine sichere Anmeldung über den Browser. Auf der Startseite **Anmelden** wählen, Zugangsdaten eingeben und nach der Rückkehr in die App sind Sie in **Ihrer** Sammlung.

Beim ersten Besuch kann ein kurzer **Einrichtungs-Assistent** erscheinen, bevor Sie zur Übersicht gelangen. Siehe [Erste Schritte](generelles-erste-schritte.md).
