# App installieren

Locobox läuft im Browser. Auf vielen Geräten können Sie die Oberfläche zusätzlich wie ein eigenes Programm installieren und danach aus dem Dock oder dem Startbildschirm öffnen. Eine Offline-Nutzung gibt es dabei nicht: Sie brauchen weiterhin eine Internetverbindung.

## Über die Ersteinrichtung

1. Starten Sie die **Ersteinrichtung** von der Karte **Locobox anpassen** auf der [Übersicht](../uebersicht/uebersicht.md) oder später unter **Einstellungen** → **Konto**.
2. Gehen Sie die Schritte **Sprache**, **Währung** und **Artikeltabelle**.
3. Auf dem Schritt **App installieren** entscheiden Sie je nach Browser:

| Situation | Was Sie sehen |
| --- | --- |
| Chrome, Edge und vergleichbare Browser, Installation möglich | Kurztext zur Installation und **Jetzt installieren**. Mit **Weiter** überspringen Sie den Schritt. |
| Locobox bereits als App geöffnet | **Locobox ist auf diesem Gerät bereits installiert.** Ohne Installations-Schaltfläche. |
| Safari | Hinweis **Locobox kann als eigenes Programm auf dem Gerät installiert werden.** und die Schritte **In Safari: «Teilen» → «Zum Dock hinzufügen».** Optional folgt der Link **Installationsanleitung** zur Safari-Hilfe. |
| Firefox (Desktop) | **Firefox bietet auf dem Desktop keine App-Installation. Für die Installation nutzen Sie Chrome, Edge oder Safari.** |

4. Schliessen Sie mit dem Schritt **Premium** und **Einrichtung abschliessen** ab.

## Über das Benutzermenü

Wenn die Installation in Ihrem Browser verfügbar ist und Locobox noch nicht als App läuft, erscheint im **Benutzermenü** (Profilbild oben rechts) der Eintrag **App installieren**. Damit öffnet sich die Installationsabfrage des Browsers.

Ist Locobox bereits installiert oder unterstützt der Browser die Direktinstallation nicht, fehlt dieser Menüpunkt. Nutzen Sie dann die Hinweise im Assistenten oder die [Browser-Hinweise](./generelles-browser-kompatibilitaet.md).
