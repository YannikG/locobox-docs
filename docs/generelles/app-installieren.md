# App installieren

Locobox läuft primär im Browser. Auf kompatiblen Betriebssystemen lässt sich die Benutzeroberfläche zusätzlich als Progressive Web App (PWA) installieren und anschliessend direkt über das Dock oder den Startbildschirm öffnen. Eine Offline-Funktionalität besteht dabei nicht: Eine aktive Internetverbindung bleibt erforderlich.

## Über die Ersteinrichtung

1. Den Assistenten **Ersteinrichtung** über die Hinweiskarte **Locobox anpassen** auf der [Übersicht](../uebersicht/uebersicht.md) oder nachträglich unter **Einstellungen** → **Konto** aufrufen.
2. Die Schritte **Sprache**, **Währung** und **Artikeltabelle** durchlaufen.
3. Im Schritt **App installieren** richtet sich das Vorgehen nach dem jeweiligen Browser:

| Ausgangslage | Angezeigte Inhalte und Optionen |
| --- | --- |
| Chrome, Edge und vergleichbare Browser mit Installationsunterstützung | Informationstext zur Installation und Schaltfläche **Jetzt installieren**. Die Schaltfläche **Weiter** überspringt diesen Schritt. |
| Locobox bereits als App geöffnet | Meldung «Locobox ist auf diesem Gerät bereits installiert.» ohne zusätzliche Installationsschaltfläche. |
| Safari | Hinweis «Locobox kann als eigenes Programm auf dem Gerät installiert werden.» sowie die Schrittfolge «In Safari: Teilen → Zum Dock hinzufügen». Ergänzend steht der Link **Installationsanleitung** zur Verfügung. |
| Firefox (Desktop) | Hinweis «Firefox bietet auf dem Desktop keine App-Installation. Für die Installation nutzen Sie Chrome, Edge oder Safari.» |

4. Den Vorgang mit dem Schritt **Premium** und der Schaltfläche **Einrichtung abschliessen** beenden.

## Über das Benutzermenü

Sofern der Browser die Direktinstallation unterstützt und Locobox noch nicht als installierte App ausgeführt wird, enthält das **Benutzermenü** (Profilsymbol oben rechts) den Menüpunkt **App installieren**. Diese Auswahl öffnet die Installationsabfrage des Browsers.

Ist die Anwendung bereits eingerichtet oder fehlt die Unterstützung im Browser, entfällt dieser Menüpunkt. In diesem Fall greifen die Hinweise des Assistenten oder die allgemeinen Erläuterungen unter [Browser-Kompatibilität](./generelles-browser-kompatibilitaet.md).
