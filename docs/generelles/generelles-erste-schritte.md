# Erste Schritte

So gelingt der Start mit Locobox:

1. Auf die Hauptseite [www.locobox.ch](https://www.locobox.ch) wechseln.
2. Von der Startseite zur App wechseln.
3. Wenn Sie noch nicht angemeldet sind, zeigt Locobox kurz die Karte **Anmelden** und leitet Sie danach zur Anmeldung weiter. Dort wählen Sie den gewünschten Weg: **E-Mail und Passwort** oder **Google**. Ein neues Konto legen Sie über **Registrieren** an.
4. Nach erfolgreicher Anmeldung öffnet sich die [Übersicht](../uebersicht/uebersicht.md).
5. Beim ersten Besuch kann die Karte **Locobox anpassen** erscheinen. Mit **Einrichtung starten** führen Sie die **Ersteinrichtung** durch (Sprache, Währung, Artikeltabelle, Premium), oder Sie wählen **Später**.

Auf der Übersicht und über die Hauptnavigation (**Sammlung**, **Züge**, **Drucken**) können Sie direkt mit der Verwaltung der Sammlung starten. Details zur Anmeldung: [Anmelden und abmelden](./generelles-anmelden.md).

## Schreibweisen in diesem Handbuch

Damit Sie sich schnell zurechtfinden, gelten in diesem Handbuch durchgehend folgende Schreibweisen:

- **Fett** kennzeichnet eine Schaltfläche, ein Feld oder eine Beschriftung, die Sie in der App sehen, zum Beispiel **Speichern**.
- «Text in Anführungszeichen» gibt den genauen Wortlaut wieder, den die App anzeigt, zum Beispiel eine Meldung nach dem Speichern.
- Ein Pfeil zeigt einen Menüpfad, den Sie nacheinander öffnen, zum Beispiel **Sammlung** → **Artikel**.
