# Funktionsmatrix-Voreinstellungen verwalten

Auf dieser Seite verwalten Sie Ihre **eigenen** Funktionsmatrix-Vorlagen. Eine Voreinstellung ist eine gespeicherte Momentaufnahme einer Funktionsmatrix, die Sie später auf andere Decoder anwenden können.

**Wo:** Hauptmenü **Sammlung** → **Decoder** → **Funktionsmatrix-Voreinstellungen**.

<LimitsPlanNote />


## Liste Ihrer Voreinstellungen

![Liste der Funktionsmatrix-Voreinstellungen mit Vorschau, Umbenennen und Löschen](/img/handbuch/decoder/decoder-voreinstellungen.webp)

Die Seite zeigt Ihre gespeicherten Voreinstellungen mit den Spalten **Name** und **Erstellt am** sowie einer Spalte **Aktionen**. Die Liste ist nach Name sortiert und seitenweise durchblätterbar.

Haben Sie noch keine gespeichert, erscheint der Hinweis «Sie haben noch keine Funktionsmatrix-Voreinstellungen gespeichert.».

## Pro Zeile

- **Vorschau** öffnet eine reine Leseansicht der gespeicherten Funktionsmatrix. Das steht allen Nutzern zur Verfügung.
- **Umbenennen** ändert den Namen (Dialog **Voreinstellung umbenennen**).
- **Löschen** entfernt die Voreinstellung nach einer Rückfrage.

**Umbenennen** und **Löschen** sind Premium-Funktionen. Ohne aktives Premium öffnet sich die Paywall; die Liste und die **Vorschau** bleiben ohne Premium nutzbar.

## Voreinstellung anlegen

Eine neue Voreinstellung erstellen Sie nicht auf dieser Seite, sondern aus einem Decoder heraus: in der **Detailansicht** eines Decoders auf dem Register **Funktionsmatrix** über **Als Voreinstellung speichern** (Premium). Locobox speichert dabei die zuletzt gespeicherte Funktionsmatrix unter dem von Ihnen vergebenen Namen.

## Voreinstellung anwenden

Anwenden können Sie eine Voreinstellung in der **Bearbeitung** eines Decoders: auf dem Register **Funktionsmatrix** im Dialog **Funktionsvorlage wählen** über das Register **Meine Voreinstellungen**. Einzelheiten unter [Funktionsmatrix](./decoder-funktionsmatrix.md).
