# Decoder-Liste

Unter **Decoder** sehen Sie alle erfassten Decoder in einer Tabelle. Filtern und sortieren Sie wie bei Artikeln; ein Klick öffnet die **Detailansicht** oder Bearbeitung.

Diese Seite wird in der laufenden Doku-Überarbeitung erweitert.
