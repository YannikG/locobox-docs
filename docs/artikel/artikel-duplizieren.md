# Artikel duplizieren

Wenn ein neuer Artikel **dem gleichen Modell** sehr ähnlich ist, lohnt sich **Duplizieren** statt alles neu einzutippen.

## So geht es

1. Artikel in der [Liste](artikel-liste.md) öffnen oder in der [Detailansicht](artikel-detailansicht.md) ansehen.
2. **Duplizieren** wählen und im Dialog bestätigen.
3. Locobox legt einen **neuen** Artikel an und öffnet dessen Detailansicht.

## Was kopiert wird — und was nicht

| Wird mitkopiert | Wird nicht mitkopiert |
| --------------- | --------------------- |
| Stammdaten und Finanzfelder (je nach Quelle) | Verknüpfung zu **Decodern** |
| **Bilder** | Eintrag in **Zügen** (Sie ordnen den neuen Artikel separat zu) |
| **Kategorien** | |

Passen Sie danach Bezeichnung, Artikelnummer und alles an, was sich vom Original unterscheidet.
