# Artikel duplizieren

In der **Artikelliste** oder in der **Detailansicht** können Sie einen Artikel **duplizieren**. Locobox legt eine Kopie an, die Sie danach anpassen (Bezeichnung, Nummer, Bilder usw.).

Diese Seite wird in der laufenden Doku-Überarbeitung erweitert.
