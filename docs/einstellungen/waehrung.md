# Währung

Unter **Einstellungen** können Sie die **Anzeige-Währung** festlegen, in der Beträge in der App dargestellt werden (z. B. CHF). Das betrifft Eingaben und Anzeigen, nicht Ihr Abonnement bei Stripe.
